# Figure 7 Analysis

This directory contains the MATLAB code used to reproduce the analyses and visualizations for **Figure 7**.

The analysis examines the low-dimensional structure of neural population activity across recording sessions using **demixed principal component analysis (dPCA)**. It quantifies latent trajectory length, relates latent dynamics to typing performance, and compares cross-session latent geometry before and after canonical correlation analysis (CCA) alignment.

## Main script

- `Fig7.m`  
  Runs the complete Figure 7 analysis, including dPCA, latent trajectory extraction, trajectory-length analysis, behavioral correlations, and cross-session alignment.

## Data

The script uses data from seven recording sessions:

`45`, `85`, `86`, `92`, `93`, `106`, and `107`.

## Running the analysis

Set the MATLAB working directory to the `Fig7` directory and run:

```matlab
Fig7_refined
```

Because later sections depend on variables and files generated by earlier sections, running the complete script from the beginning is recommended for full reproduction.

Individual figure sections can also be run separately once their required intermediate variables and result files have been generated.
